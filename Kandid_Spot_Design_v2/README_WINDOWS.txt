Kandid Spot Windows Preview
===========================

1. Right-click the zip file and choose "Extract All...".
2. Open the extracted folder.
3. Double-click START_HERE_index.html.

Important:
- Do NOT open START_HERE_index.html from inside the zip preview window.
- Keep the img folder next to the HTML file.
- Internet is required because the preview loads React/Babel from CDN.
- If the page is blank, try Chrome or Edge and refresh once.
